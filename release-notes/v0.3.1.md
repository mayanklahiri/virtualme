This point release repairs the more obvious defects left by the previous release, which had apparently decided that shipping configuration was sufficient evidence that configuration worked.

**New**

- Secret references may now use data-directory-relative files, making credentials portable with the rest of the installation without requiring absolute host paths.

**Reliability**

- Browser-agent Enter presses now use valid X11 key names, report invalid keys instead of silently admiring them, and wait for fresh page state before claiming a search succeeded.
- Project creation, editing, deletion, persistence, scheduling, and chat-task forwarding now preserve concurrent changes, reject empty runnable tasks, and avoid resurrecting deleted projects. Periodic work should now occur periodically, an ambitious standard.
- Telegram allowlists can now be edited and removed correctly, while the Config console has readable field descriptions, clearer nesting, useful type indicators, section navigation, and buttons that concede they are buttons.
- Sticky page headers now remain at the top of the viewport, live charts repaint with incoming samples, console headers agree on their anatomy, and Quick Options acknowledge clicks while waiting for the controller.
- Chromium focus handling, desktop cursor visibility, controller CSS packaging, console layouts, and Telegram authorization controls have been corrected. These were all fairly visible, which did simplify the investigation.
