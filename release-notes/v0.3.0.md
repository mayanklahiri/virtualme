Another release has arrived, carrying several new ways for the computer to remain busy while you attempt something more rewarding.

**New**

- The public documentation site now has a five-minute guide, architecture and configuration references, real console screenshots, eight shared themes, and an admirably patient explanation of what the machine is doing.
- One schema now owns the complete configuration, including strict YAML, secret references, safe atomic saves, generated documentation, and a Config page that explains which services must restart. There is finally one place to adjust things incorrectly.
- Durable assistant notifications survive restarts, synchronize read state across tabs, record clean and unclean controller lifecycles, and include an agent tool for results that deserve attention.
- Telegram can optionally join the shared conversation through authorized HTTPS long polling, exact chat and user allowlists, persistent offsets, correlated replies, and a local diagnostics page. Enabling it deliberately crosses the local privacy boundary, because even convenience has paperwork.
- The Data explorer and structured page reader make local artifacts, JSON, YAML, images, audio, and browser observations substantially easier to inspect without pretending that raw files are a user interface.

**Reliability**

- Configuration restarts, notification recovery, Telegram ingress, queue handoff, and final delivery now use durable, idempotent transitions with failure-injection and offline end-to-end coverage. Crashes remain possible, but repetition is no longer their preferred form of expression.
- Browser actuation gained more human timing, model prompts stay within the configured context, and page extraction preserves structured feeds and tables while remaining bounded. The agent now wastes fewer tokens describing that it ran out of them.
