Private background agent

Your digital life, working quietly at home.

Virtual Me uses a real local browser for plain-English tasks and recurring projects. Its memory stays on your machine, with no per-token bill for the bundled local model.

01

Run one container

Check Docker, start Virtual Me, and open port 8080.

02

Give it real browser work

03

Make useful work recur

A visible machine

The browser is real. The handoff is yours.

The agent observes pages, operates Chromium through OS-level input, and records its steps. Desktop gives you a live view and immediate takeover.

Work that waits well

Recurring projects keep their own place.

Projects

Natural-language tasks run on selectors you choose without changing chat history.

Jobs

The queue and durable activity ledger show starts, tools, durations, results, and failures.

Data

Artifacts, screenshots, project scratch files, and local history remain inspectable.

Boundary, not slogan

Your data directory survives. The trust warning matters.

Virtual Me runs as one unprivileged container with one read-write data mount. The v1 console has no authentication or TLS, so expose it only on a trusted computer and private network.

CPU first

The bundled model runs without a GPU. Local inference can be patient work.

GPU optional

Supported host GPU acceleration can improve inference, but it is not required.

No token meter

Bundled local inference has no per-token AI bill. Hardware and electricity still cost money.
